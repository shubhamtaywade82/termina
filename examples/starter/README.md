# Starter

A small termina app that uses `@nemesis-oss/termina-core` for rendering and input, and `@nemesis-oss/termina-ui` for its components. Copy this directory as the starting point for a new app.

From the repository root:

```sh
pnpm install
pnpm build
pnpm --filter termina-example-starter start
```

`pnpm typecheck` runs in CI with the other workspace packages.
